# 01 · 把 AI 用成导师，而不是答案机

> 你问「AI 就没有一点经验可以分享吗」——分享经验只是 AI 私教的**最初级用法**。
> 本篇是完整手册：六个角色、可直接复制的提示词模板、防幻觉规程、数据红线。
> 配合你已有的 grimoire MCP + WRAITH，这是「独立学习五组件」里代替「老师」的那一件。

---

## 〇、先立三条总纪律（比所有模板都重要）

1. **AI 给结构，权威源给事实。** AI 输出的 CVE 编号、版本号、参数名、API 签名，**一律二次核验**（智库检索 / 官方文档 / 本地复现）。AI 的推理通常强，细节记忆经常错——把「信推理、查事实」变成条件反射。
2. **答案机毁直觉，提问机长直觉。** 直接问「这个洞怎么打」→ 你得到答案，失去触发器（03 篇）。正确姿势是让 AI **反问你**、**批改你**、**挑战你**。凡是让 AI 替你想的环节，就是你没长进的环节。
3. **数据分层，红线不动**（沿用你 27 天计划的【7B】规则并扩展）：

| 数据级别 | 例子 | 允许进哪 |
|---|---|---|
| 公开知识 | 开源代码、公开 CVE、教程、你的方法论问题 | 云端 AI ✅ |
| 授权资产元信息 | 目标域名/IP、端口、指纹、你的假设日志（脱敏后） | **本地模型**；云端仅当委托协议明确允许且脱敏 |
| 授权资产敏感信息 | 漏洞细节、可复现 payload、拿到的凭据/数据样本 | **只进本地，绝不外出**；凭据类永不进任何 AI |
| 委托方/客户数据 | 任何真实用户数据 | **任何 AI 都不进**。这是刑事红线不是技术问题 |

## 一、六个角色 + 提示词模板

> 用法：复制模板，替换 `<尖括号>` 部分。云端 AI 用公开知识级的问题；本地模型（你的 7B）处理带目标信息的问题。**每个模板都设计成「AI 不直接给答案」的形态。**

### 角色 1 · 苏格拉底导师（学新概念时）

```
我想真正理解 <主题，如：Java 反序列化利用链>。
规则：不要直接讲解。用连续提问引导我自己推导——
每次只问一个问题，等我回答后，指出我答案里的漏洞再问下一个。
从最基础的「为什么 <核心矛盾，如：字节流能变成方法调用>」开始。
我卡住说「提示」时，你只给方向不给结论。
最后我复述一遍完整逻辑，你按「说清/推导/教人」三档给我打分（标准见 dojo/03/02）。
```

**为什么有效**：强迫你输出→暴露理解缺口→缺口处正是该查智库的地方。一轮 20 分钟 ≈ 自己读 3 小时的效果。

### 角色 2 · 复盘官（每天晚间块，15 分钟）

```
这是我的今日假设日志（已脱敏）：
<粘贴日志表格>
请做三件事：
1. 挑出我「假设排序」最可疑的一条，说明还有什么假设我没考虑到；
2. 找出我探针设计不够「最小/无害」的地方；
3. 从被否定的假设里，总结 1 条可进触发器表的「现象→假设」规则，格式照我表里现有行。
不要夸奖，直接批评。
```

**为什么有效**：这是「老师的提问」的直接替代品。你的 27 天计划晚仪式「一句话日志」升级成结构化喂料。

### 角色 3 · 出题官（月度自测前）

```
从以下题库分区抽题并出变体：<分区，如：B 越权>
规则：
1. 出 5 道新题（不能是原题照抄，要场景化：给一段响应报文/代码片段/业务描述，让我判断）；
2. 我口述作答后，你按三档（说清/推导/教人）评分，并列出我漏掉的关键点；
3. 最后指出我的知识缺口应该去查什么（给出 3 个精确检索词）。
```

### 角色 4 · 审计搭子（读代码时，仅开源/本地代码）

```
以下代码来自 <开源项目名+版本>（公开代码）：
<粘贴代码片段，含上下文>
不要直接告诉我有没有漏洞。按这个流程陪我审计：
1. 先让我找这段代码里的「汇点」（数据被当指令执行的位置），你来判对我找没找全；
2. 再让我反向追踪参数来源，每追一层你确认或纠正；
3. 追到入口后，让我判断净化是哪一级（参数化/白名单/转义/黑名单）；
4. 最后让我说出「如果这里有洞，最小验证探针是什么」（只描述，不执行）。
```

**为什么有效**：把 01 篇的「三个问题」变成陪练流程。这直接服务你 12 周课表 Track B（Java 审计）——**课上读语法，这里练判断**。

### 角色 5 · 报告审稿人（提交前，本地模型跑）

```
这是我的漏洞报告草稿（含目标信息，本地处理）：
<粘贴草稿>
按 CNVD 通用型 / SRC 平台两种标准分别审：
1. 要素完整性：版本区间、复现步骤、影响面、修复建议，缺什么；
2. 证据链：每一步截图/请求能否支撑结论，哪里会被审核员质疑；
3. 定级合理性：按平台规则我的定级会不会被打回，为什么；
4. 文字：挑出所有「夸大/模糊/口语化」表述，给出更专业的写法。
参考我库里的报告模板（cnvd-lab/docs/05）。最后给一个「提交前 checklist」。
```

> 你的 JimuReport 报告已经是专业级——这个角色的意义是**把你自己的最佳实践变成每次提交的固定质检**，让第 2 份报告和第 20 份一样好。

### 角色 6 · 翻译拆解机（读英文一手材料时）

```
以下英文材料（<来源，如：PortSwigger Research 博客>）：
<粘贴段落>
1. 逐段中文精讲（不是直译：补上作者省略的背景）；
2. 提取「机制层」结论（这篇文章的通用原理是什么，能否归入解析差异/规则盲区/信道战争）；
3. 出 2 道检验题考我；
4. 给出这段内容和我知识体系的挂接点（它属于哪条信任边界、补充我哪个 MOC）。
```

## 二、防幻觉规程（三道闸）

AI 说错话是常态不是意外。三道闸按成本从低到高：

```
闸 1 · 自检问：「这条信息你的置信度多高？哪部分可能记错？」
        → AI 自己标出的低置信部分，重点核验
闸 2 · 交叉查：具体事实（CVE/版本/API/参数）→ grimoire 症状搜索 + 官方文档/仓库
        → 你的智库在这里发挥「事实核查库」作用（6050 篇快照，2026-09 前的事实它都记得比你准）
闸 3 · 动手验：关键结论 → 本地环境复现（你的「实学优先」原则同样适用于 AI 的输出：
        AI 说的也是「别人的话」，没复现过就不进你的笔记）
```

**特别警惕三类幻觉**：

| 类型 | 例子 | 对策 |
|---|---|---|
| 编造 CVE/版本号 | 「CVE-2023-XXXXX 影响了 X 组件」实际不存在或张冠李戴 | 闸 2，必查 NVD/官方公告 |
| 过时当现状 | 拿旧版本行为断言新版本（快照知识截止问题） | 问「这个结论对应哪个版本？最新版本有变化吗」+ 查上游 |
| 似是而非的因果 | 把相关性讲成机制（「加了这个头就会被拦」） | 闸 3 本地复现；或让 AI 给出机制级解释直到你能自己推导 |

## 三、和你两个自建系统的配合战法

### 3.1 grimoire MCP：给 AI 装上你的图书馆

挂载后（`mcp_server.py`，WRAITH 的 mcp.json 同款接法，任何支持 MCP 的 AI 宿主都行），提问模式升级为：

```
「先查库再回答」模板：
  先用 kb_search 查 <关键词>，基于查到的内容回答我的问题；
  引用时标注来源文档名；库里没有的部分明确说「库外知识」——那部分我要额外核验。
```

**这个模板的价值**：把 AI 的回答自动分成「有据」（库内，可信度高）和「无据」（库外，过三道闸）两部分——防幻觉成本降一半。

症状查询的进阶用法：把**你的假设日志里被否定的现象**贴给挂了 MCP 的 AI：「kb_symptom 查这个报错，结合结果告诉我我的假设错在哪」——库+推理的合体，这是你建 MCP 接口的初衷，多数人只把它当搜索框用。

### 3.2 WRAITH 决策账本：把作战框架反过来当教材

WRAITH 有决策账本和攻击图。**学习态用法**（不是作战态）：

- 每次 WRAITH 自动决策后，让它**解释账本**：「这一步你为什么选 A 不选 B？置信度依据是什么？」——AI 智能体的决策链是你「假设排序」能力的对照样本；
- 它判断错的地方（账本里会有低置信/回退记录）是你最好的错题本：**人和 AI 在同一个地方犯错，说明那里有个你们都没建的触发器**——补进你的表；
- 它判断对而你想不到的地方，问它「你从库里哪篇学到的」→ 顺藤摸瓜回 grimoire 精读那一篇。

> 这就是「攻防智能体」和「自学道场」的闭环：WRAITH 作战产生账本 → 账本喂复盘官 → 复盘产出触发器/案例卡 → 入库 vault → 智库检索词更新 → 下次作战更强。

## 四、五个反模式（每一条都会真实发生，提前打疫苗）

| # | 反模式 | 症状 | 纠正 |
|---|---|---|---|
| 1 | **答案依赖** | 遇到现象先问 AI，不先立假设 | 铁律：**先写预测再提问**（假设日志的顺序就是为这个设计的） |
| 2 | 模板囤积 | 收藏了 50 个提示词，一个没用过 | 每个模板**当天**用一次真实的；用不上的删掉 |
| 3 | 全信或全不信 | 要么照单全收，要么「AI 都是幻觉」弃用 | 三道闸：信推理、查事实、验关键 |
| 4 | 用 AI 代替动手 | 和 AI 聊了两小时漏洞，本地环境没打开过 | 对话产出必须落在 drill/靶场验证上——聊完当天必须有「可运行的东西」（cnvd-lab 原则 1 对 AI 同样成立） |
| 5 | 敏感数据图省事 | 「就这一次把目标详情贴云端问下」 | 没有就这一次。本地 7B 慢一点是**成本**，泄露是**事故**。你的协议和刑法 285/286 条都不接受「图省事」辩护 |

## 【学习建议】

1. **今天就启用角色 2（复盘官）**——它嵌进你 27 天计划既有的晚仪式，零额外时间，收益最快。其余五个角色按场景逐个点亮，一周点亮一个就够。
2. 模板不是咒语，是**思维习惯的外骨骼**。用到第三周，你会发现自己不带模板也在这样提问（先要反问、要求分档、指定核验）——那时外骨骼就长进骨头里了。
3. 本地 7B 的能力边界要摸清：它做角色 5（报告质检）和脱敏复盘够用，做角色 1（苏格拉底深谈）会吃力——**分层用 AI**：深思考用能力强的（公开知识级问题），敏感数据用本地的。
4. 每月问自己一次：「这个月 AI 帮我长了哪个触发器？」答不出来说明你在用答案机模式，回 §四 对照自查。

## 【验收标准】

- [ ] 六个角色模板各真实使用过一次（有聊天记录/产出物为证）
- [ ] 能背出三条总纪律和数据分层表
- [ ] 抓到过至少一次 AI 幻觉并说出是哪类、走了哪道闸
- [ ] 复盘官已嵌入每日晚仪式 ≥5 天
