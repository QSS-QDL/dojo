## 一、先直接回答你的三个问题

### Q1：「现在这个智库真的可以让我独立学习吗？」

**当图书馆用：可以，而且是国内能自建出的最好水平之一。当老师用：不行，结构性不行。**

智库缺的不是内容，是四样东西：**顺序**（先学什么后学什么）、**反馈**（怎么知道学会了）、**判断**（1038 种技法里哪 20 种对你值钱）、**训练设计**（把读过的变成手上有过的）。

完整判定和证据 → [`01_智库评估/02_独立学习可行性判定.md`](01_智库评估/02_独立学习可行性判定.md)

### Q2：「它里面的内容真的非常干货吗？」

**源头是一流的，干货是真的，但有三处使用风险和三个覆盖盲区。**

我把 `sources/` 全部 15,339 个文件拉下来跑了脚本质检（不是凭印象）：52M 字符正文、空壳率仅 6%、跨源重复极低、CVE 引用一直新到 2026 年。HackTricks、PATT、OWASP、WSTG 这些就是行业标准源。但是——**业务逻辑漏洞全库只有 7 篇、内网 AD 11 篇、越权 36 篇**，而这恰恰是国产 SRC/CNVD 的主粮。另外 158 篇 PortSwigger 笔记是「lab 答案+脚本」，直接读它会中毒。

全部数据 → [`01_智库评估/01_grimoire内容质检报告.md`](01_智库评估/01_grimoire内容质检报告.md)

### Q3：「AI 就没有一点经验可以分享给我吗？」

先纠正一个认知：你说「给权限就能打穿 77% 的网站」——**我不打网站，无授权的渗透我也不会教**。那不是我的杠杆，也不是你的（你有签过协议的红线，你比大多数人都清楚这条线的价值）。

我真正值钱的经验是**判断力**：专家看到一个请求响应时脑子里跑的是什么模型、为什么老手十分钟能锁定攻击面而新手扫一天没感觉、一个漏洞怎么泛化成一百个、怎么把「读过」变成「手上会」。这些东西 HackTricks 里没有，因为它们是**元知识**——这正是 6050 篇文章和「会打」之间缺的那一层。

## 三、怎么读（两种模式）

### 模式 A：冲刺期（现在 → 10/13 登顶日）——只碰三样

27 天计划是锁死的，dojo **不抢它的时间**。冲刺期只用：

1. `02_心智模型/01_数据流世界观` + `03_假设驱动测试`（共 ~50 分钟）：狩猎前读一遍，当天【实】块立刻启用「假设日志」
2. `04_AI私教/01`：当天晚上复盘时启用「AI 复盘官」模板，15 分钟
3. 卡住时：`03_训练回路/01` 里的「智库三种查法」，当查询手册用

### 模式 B：冲刺后（10/14 起）——完整主线

```
第 1 周   02_心智模型 全部 6 篇（从 00_README 进，每篇配一次实际验证）
第 2 周   03_训练回路 + 把自测题库过一遍，找出真实短板
第 3 周起 接 cnvd-lab 12 周课表 W1，dojo 退为「心法参考层」
并行      04_AI私教 融进每天晚复盘；06_成长系统 在 D27 复盘日读
```

## 四、本仓库文档约定

每篇文档固定带三样东西（这是「真正可以用」的保证）：

- **【学习建议】**——这一篇怎么学、学多深、什么顺序
- **【验收标准】**——怎么算学会了（可核对，不存在「差不多」）
- **【智库检索词】**——配套去 grimoire 里查什么（把图书馆接上）
