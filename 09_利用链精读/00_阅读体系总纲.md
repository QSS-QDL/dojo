# 00 · 进阶阅读体系总纲：从「读文章」到「长链条」

> 你要「通读高级利用链走向巅峰」——先纠正一个姿势：**巅峰不是读出来的，是「读→重构→复现→改写」循环出来的。**
> 100 篇躺在仓库里的文章 = 0 篇读过；20 条亲手重构过的链 > 200 篇划过的报告。
> 本目录给你：阅读法（本篇）+ 精选文章库（01）+ 三大链系精读（02/03/04）+ 合法源码教材（vendor/ysoserial）。

## 一、三层阅读体系（你在哪层，读哪层）

```
L1 · 看懂层（现在 → 12周课表 W4）
   目标：任何公开 writeup 能看懂「源头→链→汇点」全路径，能画出结构图
   材料：01 篇 A 区（单漏洞报告）+ 02 篇（Java 链拆解）
   验收：读完一篇能回答四问——入口在哪？中间经过几跳？最终汇点是什么？为什么防御失效？

L2 · 重构层（W5 → W12，主力阶段）
   目标：不看原文，本地从零复现链（ysoserial 源码逐行读+改）；能把 A 报告的链
       迁移到 B 组件上（「这个链在 JimuReport 的 FreeMarker 面怎么变形？」）
   材料：02/03/04 篇 + vendor/ysoserial 源码 + vulhub 对应环境
   验收：本地打通 CC6 全链并能改动其中一环（换个触发点）仍然工作

L3 · 组合层（12 个月后，巅峰层）
   目标：自己发现「低危×低危=高危」的组合链（03 篇的逻辑链思维）；
       从补丁 diff 逆推 0day 级理解（dojo 02_心智模型/04 流水线）；写出被别人精读的报告
   材料：01 篇 C 区（研究级文章）+ 你自己的雷达表实战
   验收：一条自研组合链被 CNVD/SRC 认可为高危
```

**你现在的位置**（诚实评估）：CTF 存量+未授权强项 ≈ L1 已过、L2 起步（Java 侧）。**主攻路线：L2 的 Java 链重构（02 篇）与你的 Track B 完全同轨**——12 周课表的 J02/J03 就是它的课程化版本，两边互为练习。

## 二、消化四步法（每篇必读文章的标准流程，40-90 分钟/篇）

```
第1步 · 读（30%时间）：通读原文，只做一件事——画出「链条结构图」
        （入口→每一跳→汇点，每跳标注「依赖什么条件」）
第2步 · 重构（30%）：合上原文，凭结构图向 AI 复述这条链（苏格拉底模板，dojo 04_AI私教 角色1），
        让 AI 挑你讲错/讲漏的地方 → 回原文补
第3步 · 复现（30%）：本地环境跑通（vulhub/自建）。跑不通的链=没读懂的链。
        红线纪律：只在自己的 docker 里，真实目标永远停在「版本对号+存在性证明」
第4步 · 改写（10%）：写案例卡（五段式模板）+ 回答三个泛化问题：
        ①这条链的「模式」是什么（抽掉组件名）？
        ②同模式还会长在谁身上（我的雷达表里有吗）？
        ③防御方修哪一环最省事（=你报告的修复建议段）？
```

> **为什么第 4 步最值钱**：它把「别人的链」变成「你的家族地图一行」。没有第 4 步的阅读就是高级搬运——你的老毛病（vault 诊断 94%）在进阶层的复发形态。

## 三、版权与取材纪律（为什么有些文章只给链接）

| 材料类型 | 处理 | 原因 |
|---|---|---|
| GitHub MIT/CC 许可内容（ysoserial 等） | **拷贝进 vendor/**（署名+许可证+commit 溯源） | 许可证允许，永久离线可用 |
| 你已有的资产（Awesome-Bugbounty-Writeups / Awesome-POC / HowToHunt） | **指路不重拉**（vault vendor_src + data/Nday库 CSV） | 反重复建设 |
| grimoire 已收录源（HackTricks/PATT/BB-Writeups 索引） | **给智库检索词** | 你库里就有，检索即达 |
| 版权博客/平台文章（先知/PortSwigger Research/devco.re/个人博客） | **链接+批注+我的精读拆解** | 整篇拷贝侵权；且拆解版比原文更适合你（接你的五段式/案例卡体系） |

**离线焦虑的解法**：真正值得反复读的文章（01 篇标 ⭐ 的），用浏览器「打印为 PDF」存进你本地 vault（个人学习用途）——这合法、离线、且归你的笔记体系管。**仓库里放的是地图和拆解，不是赃物。**

## 【学习建议】

1. **今天就做的一件事**：打开 `vendor/ysoserial/payloads/URLDNS.java`（全文 60 行，唯一无害链），配合 02 篇 §一 逐行读懂它。这 60 行是整个 Java 反序列化世界的「Hello World」，读懂它=拿到 L2 的门票。
2. 通读的欲望要节制：**01 篇 100+ 链接不是清单是菜单**——按你当周主线点菜，每周 2 篇封顶。贪多必搬运动。
3. 每篇消化完的案例卡进 vault `MOC-案例库`，标题格式：`链-<模式名>-<组件>.md`（如 `链-JNDI注入-Log4j2.md`）——**按模式命名，不按 CVE 编号命名**（模式可复用，编号只可检索）。
4. L2 的复现全部在本地 docker：`vulhub` + 自建。复现环境的 docker-compose 存进 cnvd-lab `tools/lab/`（你已有这个目录结构）——环境也是资产。
