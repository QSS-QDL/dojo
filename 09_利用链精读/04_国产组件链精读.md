## 一、JimuReport SSTI → RCE（你的成名生态，链结构精读）

```
链条结构：
  报表「数据集」功能（在线 SQL/API 数据源，为业务设计=合法功能）
    └─→ 数据源/字典接口的参数进入 FreeMarker 模板求值面（queryFieldBySql 类历史接口）
          └─→ FreeMarker 内建 API：
               "freemarker.template.utility.Execute"?new()  → 命令执行
               或 TemplateModel 系（ObjectConstructor/JythonRuntime）
版本与补丁史（军备竞赛样本）：
  早期版本：模板求值直接可达 → 官方修复思路演进：接口加鉴权 → 参数过滤 Template 关键字 → 
  沙箱化（TemplateClassResolver.SAFERESOLVER 禁 ?new）→ 每轮修复都有绕过研究（B2 区检索「积木报表 绕过」）
为什么这个家族长盛不衰：
  「报表=把用户输入变成查询/模板」是产品本质功能 —— 功能与漏洞一线之隔（组合定律3：设计相乘）
识别级检测（雷达表规则）：
  /jmreport/list 可达性（未授权面正主，你的战例）→ 版本判定（页面版本号/静态资源/更新日志比对）
  → 落在受影响区间 → 本地同版本验证 → CNVD 论证
复现：vulhub 有 JimuReport 环境；或官方历史版本安装包（下载页存档）
CNVD 论证要点：版本区间（官方公告为证）+ 本地部署复现 + 影响面（被集成宿主数量——泛化四问的横向）
红线位：真实目标只证明「接口可达+版本命中」，SSTI 求值验证只在本地（?new 类探针在生产=执行面）
```

## 二、若依定时任务链（「需要后台」的链怎么变成「不需要」）

```
基础链（需管理员）：
  系统监控→定时任务（Quartz）→ invokeTarget 参数 = 直接指定「调用哪个 Bean 的哪个方法」
    └─→ 白名单校验（只允许 com.ruoyi 包前缀等）→ 历史绕过研究围绕白名单展开：
         包名前缀的字符串技巧 / 可用 Bean 里的「间接危险方法」/ 与表达式引擎组合
升级链（组合定律1+4 的实战）：
  ①默认口令 admin/admin123（一次尝试纪律）→ 直接进基础链
  ②或：越权面（07_SRC/04 §3-4）拿到管理会话 → 基础链
  ③或：Shiro key 面（若依用 Shiro 的版本）→ 反序列化直接 RCE（跳过任务功能）
教学点：「需要高权限的 RCE」的真实价值 = 它与「拿到高权限的所有低危路径」的乘积 ——
  报告里把 ①②③ 三条到达路径全部列出，评级叙事完全不同（单说任务 RCE=中危语境，
  说「弱口令/越权/默认key 三路径可达 RCE」=高危语境）
识别级检测：登录页指纹（03 篇/10 篇 §一）→ 版本 → 是否有 /monitor/job 面（登录后可见）
复现：RuoYi 官方历史版本本地部署（它是开源的——「真项目本地化」正是你 27 天计划的实学原则）
```

## 三、OA 组合链原型（三家各一条「教科书链」）

### 3a 通达型：上传 × 包含（文件操作类的组合原型）

```
第1跳：某上传点校验缺陷（后缀白名单不全/内容校验可绕/临时文件路径可预测）→ 落地一个「非 .php 但含 PHP 代码」的文件
第2跳：某包含点（LFI 面：参数进 include，历史洞多在鉴权文件/工具脚本里）→ 包含第1跳的落地文件
第3跳：PHP 代码执行 ✦
为什么 OA 是此链温床：文件功能密度极高（公文附件/头像/导入导出/皮肤上传）×历史代码包袱（鉴权 include 模式）
判定要点：单独找「上传」或单独找「包含」都难，难的是「两者的路径交集」——
  审计动作：上传点落地目录清单 × 包含点参数可控性清单，两张表交叉
复现：vulhub 通达系环境；细节版本对照 CNVD 库
红线位：落地文件用「输出 phpinfo 的标记文件」（证明执行即停，不留一句话木马——01 篇 §16 纪律）
```

### 3b 泛微型：workflow SQL 注入 → 凭据 → 后台 → 二次面

```
第1跳：流程引擎（workflow）某参数注入（历史上多个公开编号，${}/拼接面）→ 取管理员哈希/会话
第2跳：进后台 → 后台的「合法危险功能」：流程脚本/自定义页面/接口注册 → 二次 RCE 面
教学点：SQL 注入在「有后台危险功能」的系统里从来不是终点是中转站 ——
  报告的影响链要写到终点（注入本身高危，「注入→全系统控制」是严重）
审计视角（Track B 正用）：workflow/流程引擎=国产 OA 的通用架构模式，
  审计清单固定三查：流程参数拼接面 / 脚本执行功能 / 附件操作面
```

### 3c 致远型：会话接口未授权 → 管理员会话

```
历史链：某「获取会话列表」类接口未授权可达 → 返回在线用户会话标识（含管理员）→ 直接带标识访问后台
模式命名：「会话管理面暴露」—— 与 Druid session 监控页同构（10 篇 §六）！
泛化动作：见到任何系统先找「会话/在线用户管理」功能面（管理员视角的功能=攻击者的钥匙店）
```

## 四、Nacos 杠杆链（「一个配置中心=全站的钥匙」）

```
链条结构：
  ①入口：控制台默认口令 nacos/nacos（一次尝试）或 历史未授权 API（/v1/auth/users 面）
     或 UA 身份伪造（CVE-2021-29441：User-Agent: Nacos-Server 被服务端信任=身份头信任缺陷，
     与 SSRF 的 XFF 信任、寄生组件的「内网可信」假设同属一族——「来源声明当身份用」模式）
  ②立足：用户列表/权限面 → 控制台管理员
  ③杠杆：配置中心里存着什么？—— 全部接入服务的数据库连接串/Redis 密码/云 AK/JWT 签名密钥
  ④放大：任一凭据 → 对应系统的直接访问（云 AK 则接 03 篇 §三 云链）
为什么它是「杠杆率之王」：微服务架构把全站秘密集中托管给它 —— 集中度=攻击面集中度（边界地图④的极端案例）
识别级检测：8848 可达 → /nacos/ 控制台 → 版本（/nacos/v1/console/server/state 类接口回版本）→ 
  对号历史编号区间；未授权判定一发即停
红线位：读到「配置项存在数据库连接串」即停（键名+打码值证明），绝不使用其中凭据访问第三方系统
  ——用了=横向移动=越权范围（01 篇 §11 全套适用）
报告叙事：「配置中心未授权可访问，含 N 个服务的数据库凭据配置（已打码），单一缺陷可放大为全业务系统失陷」
复现：nacos 官方 docker（单机模式默认配置即历史脆弱形态）
```

## 五、WebLogic 编年史（把十年对抗史当教材读）

```
2015 CVE-2015-4852：T3 协议 + 原生反序列化（CC 链的中间件载体）——「协议即入口」
2017 CVE-2017-10271：XMLDecoder（wls-wsat 组件的 XML 解析直接构造对象=反序列化的 XML 变体）
2019 CVE-2019-2725：10271 的「修复绕过」（_async 组件同款面）——「补丁只修了实例没修模式」教学
2020 CVE-2020-14882：console 认证绕过（URL 双重编码路径）+ 后台 RCE 组合——「管理面+路径归一化」（08 篇 §七 变体表的历史大案）
2020+ 系：IIOP/T3 黑名单绕过多轮（黑名单类名 vs 新 gadget —— 与 Fastjson 演进史同构的军备竞赛）
读法（重要）：不按 CVE 编号背，按「模式演进」读——
  协议面(T3/IIOP) → 数据格式面(XMLDecoder/JSON) → 管理面(console) → 黑名单对抗史
  四个模式今天依然适用于任何新中间件（信创中间件 TongWeb/BES 的审计清单就是这四行）
判定：版本（console 登录页/报错/响应头）→ 编号对号 → vulhub 全系复现（weblogic 环境最全的一家）
红线位：全部复现在 vulhub；真实目标只做版本判定+console 可达性
```

## 六、三合一定律：国产组件链的元模式（本篇的「道」)

```
几乎所有国产组件高危链 = 以下三要素中至少两个的组合：
  ①管理面暴露：控制台/监控/调度/配置中心可达公网（寄生组件边界失守，dojo 02_心智模型/02 §四）
  ②默认/弱凭据：出厂口令未改（nacos/nacos、admin/123456、druid/druid……一次尝试纪律）
  ③动态执行功能：产品的「合法功能」里含表达式/模板/脚本/任务调度/类加载
     （报表=模板引擎，调度=反射调用，流程=脚本，规则引擎=表达式——功能即汇点）
组合判定卡（新组件 10 分钟预判法）：
  它是管理面吗？→ 默认口令清单有它吗？→ 它有什么「动态执行」功能？→ 三问两中=高危候选，进雷达表重点行
应用：每次遇到没见过的国产组件（信创采购的新中间件/新低代码平台），先过三问再谈扫漏洞 ——
  这就是「家族地图」的生成器（10 篇 §八 工程化的思维内核）
CNVD 通用型选题公式：
  高发行量组件（若依/Jeecg 衍生系）× ①②③组合面 × 版本区间可论证 = 证书产线
```
