# 02 · 心智模型（dojo 核心目录）

> 六个可训练的思维框架——「判断力层」的全部交付物。
> 图书馆（grimoire）教你**是什么**，课程（cnvd-lab）教你**怎么做**，这里教你**怎么想**。

## 六模型总览（一条完整的认知链）

| # | 文件 | 一句话内核 | 回答的问题 |
|---|---|---|---|
| 01 | [数据流世界观](01_数据流世界观.md) | 所有漏洞都是同一条河：不可信数据流进把它当可信的位置 | 「这个功能的洞可能在哪？」 |
| 02 | [边界地图](02_边界地图.md) | 攻击面是画出来的：十二条信任边界各有特产漏洞 | 「这个系统该从哪测起？」 |
| 03 | [假设驱动测试](03_假设驱动测试.md) | 新手撒网，专家狙击：观察→假设→最小探针→神谕→更新 | 「怎么测得又快又合规？」 |
| 04 | [闻一知十](04_闻一知十.md) | 一个洞是事件，一类洞是资产：实例→模式→类→生态 | 「找到洞之后干什么？」 |
| 05 | [报文即证据](05_报文即证据.md) | 报文是系统的自白书，30 秒建立目标模型 | 「不发 payload 能知道什么？」 |
| 06 | [防御者视角](06_防御者视角.md) | 绕过=解析差异+规则盲区；防御方能杀死的是你的神谕 | 「被 WAF 拦了怎么办？」 |

## 依赖关系与建议读法

```
01 数据流 ──► 02 边界 ──► 03 假设回路 ──► 04 泛化
                ▲                ▲
             05 报文证据      06 对抗（用到再深读）
```

- **完整学**：按 01→06 顺序，每篇读完立刻做篇末练习（练习才是本体）。六篇+练习 ≈ 12-15 小时，建议一周内完成，每篇配一次真实/靶场验证。
- **冲刺期急用**（27 天计划期间）：只读 01+03（50 分钟），当天【实】块启用「假设日志」。
- **每篇的固定结构**：内核 → 展开 → 练习 → 验收标准 → 智库检索词 → 学习建议。验收标准不过 = 没学，重做练习。
