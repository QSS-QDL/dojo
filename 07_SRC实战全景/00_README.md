## 三个使用纪律

1. **止损线优先于技巧**。每个情境的「何时放弃」不是软弱，是让你能一直干下去的设计。SRC 的收入曲线是长尾的：**大部分时间无产出，产出集中在少数几个「对了」的时刻**——所以保住时间和授权额度比多试一个 payload 重要。
2. **红线组（01 篇）任何时候优先**。其余 100+ 情境都在红线之内求解；如果一个处置方案需要越线，那个方案就是错的，不管技术上多优雅。
3. **情境会复利**。你自己撞到的新情境，按四段格式补进对应篇章末尾（编号续下去）。这份文档最终的价值在于它变成**你的**情境库——我的 108 条只是起手。

## 与心智模型的关系

本目录是**战术层**（此刻怎么办），`02_心智模型` 是**判断层**（为什么会这样、下一步该想什么）。
正确用法：情境卡给你动作，心智模型给你动作背后的理由。
只背情境卡 = 又变成搬运型（你的老毛病）；每次用完一张卡，问一句「这背后是哪个模型」，卡才会变成你的。
