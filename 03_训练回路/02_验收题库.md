# 02 · 验收题库：你怎么知道自己真的会了

> 用途：**月度自测**。每月最后一周，从当前主线相关主题抽 10 题，
> 用「三档作答法」自测，分数记进 vault 的 `度量表.csv`（你已有这张表，直接加列）。
> 出题人可以是 AI（`04_AI私教` 的「出题官」模板），但**评分标准必须用本篇的三档**。

---

## 一、三档作答法（评分标准）

每题按你能达到的档位计分：

| 档 | 标准 | 分 |
|---|---|---|
| **L1 说清** | 能用术语准确描述它是什么、怎么发生的 | 1 |
| **L2 推导** | 不看资料，能推导出检测方法和至少一种变体/绕过 | 2 |
| **L3 教人** | 能给外行讲明白本质，**并能说出「什么时候它不成立」**（适用边界） | 3 |

- 作答方式：**口述录音或限时 5 分钟手写**（打字太慢会打断思维，也容易复制粘贴自欺）。
- 答完对答案：让 AI 按三档给你打分并要求它**指出你漏掉的关键点**。
- 目标不是满分：**L1 全覆盖 + 主线主题达 L2 + 你的成名技达 L3**（比如未授权访问你该是 L3）。
- 任何题答不出 L1 → 进本周缺口清单，用「智库姿势 C」补。

## 二、题库

### A · 数据流与注入（对应 01 篇）

1. SQL 注入的参数化查询为什么能根治？它防不住的注入变体是什么？（L3 提示：order by / 表名列名 / like 拼接）
2. 什么是二次注入？给出一个「存储时安全、使用时爆炸」的具体场景。
3. XSS 的三种上下文（HTML body / 属性 / JS 字符串）各需要什么转义？为什么「统一 htmlspecialchars」不够？
4. SSRF 的完整危害链是什么？（从读 metadata 到内网组件未授权，按你的边界图讲）
5. 为什么反序列化是「数据变指令」的极端形态？PHP 和 Java 的利用链构造思路差在哪？
6. MyBatis `#{}` 和 `${}` 的区别，以及 `${}` 什么场景下不得不使用、怎么补救？
7. 命令注入里，为什么 `escapeshellarg` 和 `escapeshellcmd` 混用会出事？（L3 题）
8. 给你一个「搜索功能」，列出它的完整源头清单（不止输入框）。

### B · 边界与越权（对应 02 篇，你的出单主力）

9. 水平越权和垂直越权的最小探针分别是什么？为什么必须用双账号测？
10. 「前端藏了菜单」为什么等于没鉴权？后端鉴权缺失的三种常见成因（拦截器漏配 / 网关白名单过宽 / 组件自带接口）。
11. 寄生组件边界失守的家族逻辑：为什么宿主的登录闸保护不了内嵌组件？举 4 个家族成员。
12. IDOR 测试时，「403」和「404」和「200+空数据」三种响应各说明什么？哪种最值得深挖？
13. 异步任务（导出/报表/转码）为什么是越权重灾区？所有权校验通常漏在哪一步？
14. OAuth 流程里 `redirect_uri` 的三种常见校验缺陷（精确匹配缺失/前缀匹配/路径穿越）。

### C · 假设与神谕（对应 03 篇）

15. 什么是「最小探针」？它和「直接发 payload」在合规与信息量上的三个区别。

17. 时延探针突然全部失效，你的三种解释和对应的下一步探针是什么？（信道战争）
18. 假设被否定时，哪三种「为什么被否」必须记录？（闸拦了/没入库/上下文不对）
19. 40 分钟时间盒到了但你有「强烈感觉快出洞了」，决策规则是什么？

### D · 泛化与 CNVD（对应 04 篇）

20. 泛化阶梯四级是什么？用你自己的 JimuReport 案例各说一句。
21. 补丁 diff 流水线的六步？为什么「安全公告不给细节的版本更新」是最佳信号？
22. 网站漏洞和通用型漏洞的判定分界是什么？（提示：版本区间）CNVD 提交需要哪些要素？
23. 「假家族」陷阱：为什么不能按表象（都叫未授权）归类？按什么归？
24. 三次成脚本纪律：你的哪些手工验证已经该脚本化了？（自查题）

### E · 报文与指纹（对应 05 篇）

26. 403 的三种出身（WAF/中间件/应用）怎么用一个请求区分？

### F · 对抗与防御（对应 06 篇）

## 三、使用节奏

```
每月最后一周：
  1. 从当月主线相关分区抽 10 题（AI 出题官可以打乱+变体，防背题）
  2. 限时作答（5 分钟/题）→ AI 按三档评分
  3. 总分 + 各分区 L1 覆盖率 → 记入 度量表.csv
  4. L1 都不到的题 → 下月训练计划的输入
```

**分数怎么用**（重要）：分数**只和自己上月比**。它的用途是「暴露自以为会了的地方」，不是绩效考核。连续两个月同一分区不涨 = 该分区的学法有问题（回 `03_训练回路/01` 检查四要件），不是你不努力。

## 【学习建议】

1. 第一次自测建议就从 **B 区（越权）** 开始——它是你的出单主力也是智库最薄区，分数最能指导投入。
2. 口述作答可以对着 AI 说（语音转文字），让 AI 立刻按三档打分——这就把「月度考试」变成「随时可练」，成本降到 5 分钟/题。
3. 自己出题：每次实战命中一个新洞，**当天把它变成一道题加进对应分区**（「我这次是怎么想到的」就是最好的 L2/L3 题）。题库自己长，才是你的题库。
4. 别追求 39 题全 L3。**L3 只留给你的成名技和吃饭技**（对你现在是：未授权/寄生组件家族），其余 L1-L2 就够用——判断力要配称野心，但也要配称战线。
