# 01 · 40 小时速通法：给任何新领域自建课程

> 用途：12 周课表之外冒出的新领域（云安全 / AI 安全 / 二进制 / 供应链……），
> 不报课、不等教程，用这套流程 **40 小时**把它从「陌生」推到「能出第一个成果」。
> 理论依据：`01_智库评估/02` 的五组件 + `02_心智模型/02` 的「新技术=新边界」。

---

## 〇、第 0 步：先问「现在值得学吗」（30 分钟，可能省下 40 小时）

三个筛子，全过才开工：

| 筛子 | 问题 | 不过关的信号 |
|---|---|---|
| 主线相关 | 它离你当前的变现线（SRC/CNVD）几步远？ | ≥3 步远 → 放进「第二年清单」，现在不碰 |
| 智库存量 | grimoire 里这个主题有多少篇？ | >300 篇 = 材料已备好，速通成本低（云 728 / AI 542 都达标）；<20 篇 = 要先解决材料问题，成本翻倍 |
| 半衰期 | 这个领域的知识多久贬值一半？ | 越短越要「现在学现在用」，长半衰期领域可以排队 |

> **反面示范**：2024-2025 年无数人在 HW 失利焦虑下冲去学内网 AD——对你当时是「3 步远 + 智库仅 11 篇」，双筛不过。cnvd-lab 诊断里那句「你优先级排序比多数人清醒」说的就是拒绝了这种焦虑式学习。速通法的第一课是**不通**。

---

## 一、4 小时：建图（不动手学技术，只画地图）

新领域的瓶颈从来不是材料，是**不知道材料的形状**。四个建图动作：

### 1.1 边界模型切入（1h）——用 02 篇的万能钥匙

问三个问题，答案就是领域的骨架：

```
① 这个领域新增/改变了哪条信任边界？
② 闸是什么形态？（策略文件？签名？沙箱？速率限制？权限模型？）
③ 闸的解析器和执行器可能在哪里不一致？（→ 特产漏洞猜想清单）
```

**示范（云安全）**：① 边界从网络 perimeter 变成 IAM 身份 perimeter ② 闸=policy 文档+角色链 ③ 不一致点=「权限策略的解释」vs「各服务实际执行的鉴权」→ 特产猜想：权限提升路径、 confused deputy（让高权限服务替你干低权限不能干的事）、元数据凭证窃取。**看，还没读任何教程，攻击面清单已经有了。**

### 1.2 顶级信源扫描（1h）

固定动作：① grimoire 搜领域词，数篇目、翻 10 篇看深度（你已经会质检了，用 01 篇的方法）；② GitHub 搜该领域 top3 仓库（按 star+最近更新）；③ 找该领域的「PortSwigger Research 等价物」——最出原创研究的那个信源（云：Rhino Security / Datadog 博客；AI：Simon Willison / 各模型厂商的 red-team 报告）。

### 1.3 从业者词表（1h）

收集 30 个「不懂就无法读社区帖」的术语（云：IR role / bucket policy / SCIM / IMDSv2…；AI：system prompt / tool call / RAG / jailbreak / evals…）。**每个术语一句话解释**（问 AI，过防幻觉三道闸）。这张表是你后面 30 小时的词典。

### 1.4 定脊柱任务（1h）——速通法的灵魂

**不选书，不选课，选一个「做完就等于入门」的真实任务**：

| 领域 | 脊柱任务示范 | 完成标志 |
|---|---|---|
| 云安全 | 本地跑通 CloudGoat（智库有 196 篇文档）的 iam_privesc + 另选 2 个场景 | 3 个场景的 writeup 案例卡 |
| AI 安全 | 自建一个带工具调用的本地 Agent，然后成功对它做 3 类攻击（直接注入 / 间接注入 via 文档 / 工具滥用） | 3 张案例卡 + 一个「Agent 边界图」 |
| K8s | K8s-Goat（智库 170 篇）通杀一半关卡 | 关卡笔记 + 一张 K8s 边界图 |
| 二进制 | 挑一个有公开补丁的简单栈溢出 CVE，从补丁 diff 到本地复现 | 完整走通 04 篇流水线（跨域复用！） |

脊柱任务的选择标准：**有明确的「做完了」信号 + 覆盖领域主干（不是边角料）+ 材料在智库/本地可及**。

## 二、30 小时：主攻脊柱任务（拆成 5-7 个检查点）

把脊柱任务拆成检查点，每个检查点 4-6 小时，**沿用主线的全套纪律**：

```
每个检查点的循环（和 03 篇训练回路完全同构）：
  卡住 → 智库姿势 A（症状查询）→ 还卡 → 上游文档/顶级信源 → 还卡 → AI 苏格拉底（角色1）
  通过 → 假设日志记一行 → 案例卡/词表更新 → 下一检查点
时间盒：单检查点超时 6h → 记录阻塞原因，跳下一个，回头补（防止一点卡死全局）
```

**30 小时的分配现实**：约 40% 在搭环境和排错（这是正常成本，不是浪费）、40% 在任务本体、20% 在「顺藤摸瓜的分支学习」（摸出去的瓜记进词表和缺口清单，超过 30 分钟的分支强制斩断——速通期间深度让位于覆盖）。

## 三、6 小时：输出与验收（没有这一步，40 小时打六折）

| 动作 | 时长 | 产出 |
|---|---|---|
| 费曼讲给 AI | 1h | 用苏格拉底模板把领域骨架讲一遍，让 AI 挑错；错处回炉 |
| 公开笔记 | 2h | 一篇脱敏 writeup/领域地图博客（`02_输出系统` 的影响力资产） |
| 案例卡+入库 | 1h | 脊柱任务拆成案例卡进 vault MOC；新触发器进表 |
| 自测 | 1h | 让出题官按三档出 8 题（领域版 G 区），L1 全覆盖 = 速通成功 |
| **去留决策** | 1h | 三选一：**深入**（进 12 周课表级别的系统学习）/ **挂起**（地图+词表留着，需要时 8 小时复活）/ **关闭**（确认与我无缘，写一行为什么） |

> **「挂起」是速通法最被低估的成果**：40 小时后你不需要精通，你需要的是「下次遇到这个领域的问题，能在 10 分钟内知道去哪查、找谁问、什么值得警惕」。地图+词表+案例卡就是这个状态的可携带形式。

---

## 四、三个反模式

1. **收集地图代替走路**：收藏了 5 个 roadmap 仓库、3 门公开课，脊柱任务没开工。→ 纪律：建图阶段结束时脊柱任务必须已写下「第一步的具体命令」。
2. **教程依赖**：跟着视频一课一课看，感觉很好，脱离教程寸步难行。→ 纪律：视频/教程只在检查点卡住时按段查，**主线永远是任务本身**。
3. **完美主义收尾**：「等我把 IAM 全学完再做场景三」。→ 纪律：40 小时到点就进 §三 输出，残缺的完成 >> 完美的烂尾。

## 【学习建议】

1. **第一次实战建议选 AI 安全**：智库存量 542 篇（材料免检）、离你的 WRAITH/nuwa 生态最近（脊柱任务=打你自己的 Agent，天然合规）、半衰期短（现在学现在值钱）。云的 728+196+170 篇留作第二次速通的弹药。
2. 速通期间**主线（12 周课表）降档不熄火**：每周至少保留 1 个主线 drill，防止新领域变成逃避主线的兔子洞（06 篇 §二 会讲这个心理机制）。
3. 每次速通结束后修订本篇：你的 40 小时分配比例、检查点粒度都会随经验变化——**这篇文档本身也该被泛化阶梯对待**（实例→模式→类→生态：你的第 3 次速通会发现自己有了「速通风格」）。
